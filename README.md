Этот проект представляет собой базовое приложение чата, реализованное на Python, которое использует сокеты для сетевого взаимодействия между клиентами и центральным сервером. Архитектура основана на модели "Клиент-Сервер".
Функционал
Многопоточность: Использование потоков (threading) позволяет клиенту одновременно принимать входящие сообщения от сервера и отправлять исходящие сообщения, делая интерфейс отзывчивым.
Вещание: Сервер обрабатывает все входящие сообщения и рассылает их всем подключенным пользователям, кроме отправителя.
Управление сессией: Автоматическое обнаружение отсоединения клиента.
Структура Файлов и Описание Кода
Проект состоит из двух основных компонентов: server.py (сервер) и client.py (клиент).
server.py — Серверная Часть
Этот файл выполняет роль центрального коммутатора чата. Он слушает порт, принимает всех подключенных пользователей и обеспечивает маршрутизацию сообщений между ними.
Как работает:
Инициализация: Создает сокет на заданном адресе (0.0.0.0) и порту (5555), делая его доступным для подключения из любой сети.
Прием подключений (Main Loop): Запускается бесконечный цикл, который ждет новых входящих соединений (server_socket.accept()).
Авторизация/Идентификация: При каждом новом подключении сервер ожидает получить от клиента первую строку — это и будет его никнейм.
Обработка клиента (Thread): Для каждого нового пользователя запускается отдельный поток (handle_client), который полностью изолирует логику работы с этим пользователем.
Прием и Вещание: В потоке handle_client сообщения непрерывно принимаются от данного клиента. После получения, сообщение форматируется (добавляется никнейм) и рассылается (broadcast) всем остальным подключенным клиентам, кроме отправителя.
Управление состоянием: Сервер хранит список всех активных сокетов и их соответствующие никнеймы в словарях clients и nicknames. При отключении клиента он удаляется из этих структур.
client.py — Клиентская Часть
Этот файл представляет собой оконечное устройство, которое пользователь использует для взаимодействия с чатом.
Как работает:
Ввод Никнейма: При запуске запрашивает никнейм у пользователя.
Подключение: Создает сокет и пытается подключиться к серверу по адресу HOST:PORT.
Первичная авторизация: Отправляет свой никнейм на сервер, что выполняет роль "логина".
Многопоточность: Запускается отдельный поток (receive_messages), который бесконечно ждет и принимает любые сообщения от сервера. Это гарантирует, что чат не блокируется ожиданием ввода пользователя.
Основной цикл: Главный цикл программы ожидает ввода команды от пользователя. При вводе текста он отправляет его на сервер.
