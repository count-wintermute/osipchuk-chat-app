Для разработки проекта применялись LLM локально развернутые при помощи LMstudio, которое было выбрано благодаря удобному визуальному интерфейсу. ПО техническим причинам я мог потянуть только две актуальные модели Gemma 4 E4B и Qwen3 4B Thinking 2507. Обе из них хоть и легковесные имеют некую долю специализации в помощи создания кода- Gemma более мощная но с меньшей специализацией, Qwen- имеет большую специализацию но слабее. Они использовались для первоначальной генерации кода в частности один из промптов был "I need code for a simple online chat app where users can choose their own nicknames. Use minimal dependancies. Code should be in python. Keep it as simple as possible". В последствии только код базированный на коде Gemma был использован(он содержится в папке chat-app1.0). Qwen растратило слишком много токенов и код был слишком запутанным для того чтобы его мог починить человек(я). Gemma смогла работать с простой файловой системой "сервер-клиент". Тем не менее работа с Qwen была полезна в практике создания Dockerfile.   
Тестирование проходило на одном ноутбуке с двумя виртуальными машинами. Сервер и два клиента.
